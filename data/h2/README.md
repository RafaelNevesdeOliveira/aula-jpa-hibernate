# Base H2 local

Arquivo gerado em `laboratorio.mv.db` ao rodar `org.caixaverso.App` ou `ConsoleH2`.

- JDBC URL: `jdbc:h2:file:./data/h2/laboratorio;AUTO_SERVER=TRUE`
- Usuario: `sa`
- Senha: vazia
- Dados iniciais: `../json/contas.json` e `../json/pessoas.json`
